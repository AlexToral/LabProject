# Módulo de IA (etapa opcional)

Esta carpeta está reservada para la etapa 5 del roadmap: segmentación experimental de la vena subclavia con U-Net (PyTorch).

**La etapa es opcional y está condicionada a datos.** No debe comenzar hasta que exista un conjunto de imágenes suficiente, anonimizado, calibrado, anotado por especialistas y con autorización documentada para su uso (ver issue E5-01).

- `notebooks/` — exploración y experimentos.
- `src/` — código reproducible de preprocesamiento, entrenamiento y evaluación.

Las imágenes, máscaras y pesos de modelos no se guardan en Git.
